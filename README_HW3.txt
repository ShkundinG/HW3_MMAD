Домашняя работа №3 — логистическая регрессия, метрики, дисбаланс классов, Streamlit.
Автор: Шкундин Глеб.

Содержимое архива:
  HW3_MMDA_Shkundin.ipynb — заполненный и выполненный ноутбук с графиками, таблицами и моими выводами.
  wine_quality.csv — исходные данные для ноутбука.
  requirements_notebook.txt — зависимости ноутбука для Python 3.13.
  wine_app/ — приложение Streamlit, готовая модель, порог, тестовые данные, requirements.txt и README.md.

1. Распакуйте архив целиком.
2. Установите Python 3.13 и зависимости:
   python -m pip install -r requirements_notebook.txt
3. Откройте HW3_MMDA_Shkundin.ipynb в Jupyter или VS Code и выполните ячейки сверху вниз.
4. Для запуска приложения:
   python -m pip install -r wine_app/requirements.txt
   streamlit run wine_app/app.py
5. Для публикации приложения на Streamlit Community Cloud см. wine_app/README.md.

Код в ноутбуке и app.py не содержит комментариев. Модель и порог уже сохранены, запуск приложения не требует обучения.

Публикация на Streamlit Community Cloud требует входа в GitHub и Streamlit и выполняется владельцем аккаунта.
